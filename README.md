# GeoTransformer PPT

This private repository contains the focused GeoTransformer presentation and its source paper.

## Files

- `ppt/geotransformer_deep_dive.pptx`: focused explanation of GeoTransformer, covering model structure, input/output flow, experiments, ablations, qualitative figures, and engineering notes.
- `papers/geotransformer.pdf`: source paper, "Geometric Transformer for Fast and Robust Point Cloud Registration", CVPR 2022.

## Source

- Paper: https://openaccess.thecvf.com/content/CVPR2022/papers/Qin_Geometric_Transformer_for_Fast_and_Robust_Point_Cloud_Registration_CVPR_2022_paper.pdf
- Code URL shown in the paper: https://github.com/qinzheng93/GeoTransformer
